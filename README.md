# 🎉 Teachers' Day Message Card

A simple and interactive web project that allows users to create a personalized **Teachers’ Day greeting card** with a custom message, sender name, and confetti celebration animation.  
Built with **HTML**, **CSS**, and **JavaScript**.

---

## 🌐 Project Overview

This project displays a message card for Teachers’ Day that users can personalize.  
You can enter the teacher’s name, your name, and a message — and the card will update dynamically.  
Click the **“🎉 Celebrate”** button to trigger a confetti animation for a festive effect!
